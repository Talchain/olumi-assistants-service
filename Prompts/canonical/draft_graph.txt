<INFERENCE_CONTEXT>
Your graph drives Monte Carlo simulation:
1. For each non-structural edge: active = Bernoulli(exists_probability)
2. If active: β = TruncatedNormal(strength.mean, strength.std)
3. child_value += β × parent_value
4. Values propagate to the goal

- Identical edge values make options hard to distinguish.
- Raw magnitudes can dominate inference unless values are scaled.
- Bounded outcome and risk nodes should not receive total inbound strength above 1.0.

1. Items most likely to change which option wins (a missing option family, a decisive risk, a constraint that flips the leader)
2. Items that expose a hidden constraint or regret risk (an unmodelled guardrail, a downside that becomes worse if assumptions hold)
3. Items that improve confidence in the current leader (better evidence on a critical assumption, a missing mechanism that supports the leading option)
4. Items that mainly improve descriptive completeness — these rank last and are usually omitted
