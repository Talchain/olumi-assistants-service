# Lane D — bounded quality-system extension

Extends #1233. Tools and evidence only; no serving source, prompt, model routing,
canonical state or deployment changes. This does not hold or activate #1228.

## What the operator can now distinguish

Wrong prompt/model/brief/component binding is rejected. Grammar acceptance is
separate from semantic fidelity. Original responses are checked against real
target schema/parser/projector/consumer functions and independently authored
diagnostic/action twins. Stored PASS annotations cannot certify a replay.
Unknown source, recorder, configuration or promotion evidence stays UNVERIFIED.

The recorder's ESM SDK identity is tested with a native, no-network adapter
replay. The initial CJS interceptor defect was caught before any provider call.
Static probe source agreement includes the complete source/dependency boundary;
matching entrypoints alone cannot hide a different projector.

reasoned estimates, priors, prospective effects or legitimate explicit zero.

PASS from keyword overlap. The historical 54 + hybrid 2 corpus remains intact.

These are local production-adapter observations, not mounted or deployed
behaviour. Candidate + old instruction is intentionally labelled as such; this
experiment neither repeats nor replaces #1228's candidate + new instruction
evidence. No prompt promotion is licensed. Known diagnostic/numeric failures
are handed back to CC/semantic ownership, not fixed inside Lane D.

## Reproduce without new model calls

`provider-and-serving.tar.gz` SHA-256:
`843b9dd5adf5a38fe87484f406eba591fdc3c1f42f1b3bd79636c0f552c54bd9`.
It contains the original complete request/response/consumed-output captures,
three read-only serving snapshots, and original summaries. No credentials or
authentication headers are stored. Extract into a fresh directory, use the
exact target checkout and run the README's `--packet` command with
`--snapshot <extracted>/draft-after.json`. Repeat with the reworded pair ID.

The packet re-derives verdicts; it does not trust the archived summaries. Its
rollback pointer retains the incumbent code plus complete original PMS/model
selection for both environments. Candidate numeric PMS version is not invented.
Actual promotion, rollback, refreshed post-action cache evidence and fleet
convergence remain UNVERIFIED and CC-owned.
