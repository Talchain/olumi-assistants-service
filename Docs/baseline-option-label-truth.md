## What changes

The final records acceptance boundary runs after optional completion. A narrow whole-utterance framing guard can recover only an actual unique merged refinement with represented numerical effects. It retains the option ID, effects and original quotation while marking the alternative and its label as AI inferred. It does not claim the user stated “Hold Price”, nor establish that an AI suggestion is strategically appropriate.

With no safe refinement, the invalid option and its incident links leave the projected option set. The original records and an explicit framing disclosure remain. Two or more genuine alternatives continue through ordinary readiness/calibration; an incomplete choice set returns the existing typed recovery response before repair or GRAPH_READY. The native response explicitly tells the user about the unresolved gap. No baseline label or effect is generated by this correction.

The guard does not treat the existing label author's refusal as semantic classification: “we could keep prices unchanged”, “Hire a researcher to figure out customer demand”, and “Launch the campaign named Why Pay More?” must remain genuine options. This bounded guard is not a general natural-language classifier.
